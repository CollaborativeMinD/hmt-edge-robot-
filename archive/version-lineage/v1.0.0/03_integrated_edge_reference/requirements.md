# Integrated edge requirement summary

The current integrated cell binds requirements to executable sources and regression tests across:

- Access authority: provisioned identities, scoped leases, expiry, revocation, presence, policy epochs.
- Safety: freshness/frame guards, path separation, protective distance, SIL admittance.
- Edge health: bounded telemetry, hysteresis, power/thermal lanes, invalid-data gaps, critical shutdown.
- Vision/geometry: ranked PCA candidates, ambiguity rejection, PGA calibration, frame provenance.
- Orchestration: bounded queue, transactional admission, duplicate prevention, state law, driver acknowledgment, feedback verification, restart reconciliation.
- Evidence/analytics: append-only hash chain, verified projection, Polars/DuckDB aggregation, atomic Parquet export.
- Resident HMT: seeded classical ML baseline, bounded evidence context, schema admission, allowlisted advisory tools, provider qualification, no actuation authority.
- Nonfunctional gates: strict finite contracts, request/body/rate bounds, bounded capacities, replay integrity, evidence-before-side-effect, observed SIL timing/RSS margins, <=60-line functions, requirement/test/ontology bindings, offline suite coverage >=90%.

External hardware deployment, calibrated physical stopping behavior, firmware static-memory/MISRA gates, distributed HA, and statistical ML qualification remain HOLD until external evidence exists.
